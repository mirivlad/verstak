## Highlights

- The Deal opens on where you stopped, not on a wall of cards. `Continue working` used to repeat the same urgent todos and unsorted Browser captures that `Needs attention` was already showing, so the first screen said everything twice and led nowhere in particular. It now holds only real points of return — notes, files, journal entries — and reads top to bottom as one question after another: where I stopped, what needs a reaction, what is in the Deal, what changed recently. An attention panel with nothing in it no longer takes up space.
- Overview and Search are fed by plugins rather than by the shell reading their storage behind their backs. The shell used to open the storage of specific official plugins and know what their keys meant; a plugin outside that hardcoded list could not appear on the Deal's first screen or in global search at all. Both now consume declared provider contributions, so what you see is what the plugins actually offer — including a third-party one.
- Folder colours and icons belong to the application. They were split between core storage and a `verstak.folder-appearance` plugin that duplicated the built-in picker and declared a contribution point the runtime never supported. The plugin is retired and appearance set through it is migrated on first read; nothing needs to be re-chosen.
- Search results for folders open the folder. The Search provider had been asking the platform to resolve a workspace path — a published SDK contract the desktop runtime did not implement — so a folder could be listed with an action that did nothing.
- After switching language, Overview reloads its saved labels. `Overview.md` no longer keeps an English `Open Notes` in a Russian interface.

## Главное

- Дело открывается на том, где вы остановились, а не на стене карточек. `Продолжить работу` повторяло те же срочные задачи и неразобранные захваты браузера, что уже показывало `Требует внимания`, — первый экран говорил всё дважды и никуда конкретно не вёл. Теперь там только настоящие точки возврата: заметки, файлы, записи журнала, — и экран читается сверху вниз как последовательность вопросов: где я остановился, что требует реакции, что есть в Деле, что недавно изменилось. Пустая панель внимания больше не занимает место.
- Overview и Поиск наполняют плагины, а не оболочка, читающая их хранилище у них за спиной. Раньше оболочка открывала хранилище конкретных официальных плагинов и знала, что значат их ключи; плагин вне этого зашитого списка не мог появиться ни на первом экране Дела, ни в глобальном поиске вообще. Теперь оба потребляют объявленные вклады провайдеров — вы видите то, что плагины действительно предлагают, включая сторонний.
- Цвета и иконки папок принадлежат приложению. Они были поделены между хранилищем ядра и плагином `verstak.folder-appearance`, который дублировал встроенный выбор и объявлял точку вклада, никогда не поддерживавшуюся рантаймом. Плагин выведен из состава, а оформление, заданное через него, переносится при первом чтении — выбирать заново ничего не нужно.
- Найденная папка открывается. Провайдер поиска просил платформу разрешить путь в рабочем пространстве — опубликованный контракт SDK, который рантайм не реализовывал, — поэтому папка могла показываться с действием, которое ничего не делало.
- После смены языка Overview перечитывает сохранённые подписи. `Overview.md` больше не остаётся с английским `Open Notes` в русском интерфейсе.

## Under the hood / Под капотом

Ничего из этого не видно в окне, но это то, из-за чего предыдущие сборки ломались молча.

- The E2E suite runs the plugin frontends the product ships. Four of them — Trash, Search, Platform Test, Sync — were executed from a second implementation written inside the test mock, so the suite was green about code nobody installs. That implementation is gone, 1364 lines of it, and a source contract fails if one grows back.
- The icon contract no longer depends on which plugins happen to be installed on the machine running it. It read a local install copy alongside the plugin sources, so the same commit could be red on one machine and green on another — which is why one icon drift looked like it kept returning.
- A change to the official plugins now runs the desktop contract that depends on it. Retiring a plugin there used to break the desktop build in a repository whose own CI had no reason to run; that break stayed invisible for days. Desktop checks also run nightly against the dependency they pin to a moving branch.
- The Wails binding check is derived from the Go API instead of a hand-written list of ten method names. It covers 133.

## Packages / Пакеты

A Debian package and an AppImage for Linux, with the matching official plugins bundled. The browser extension and the sync server are unchanged in this build.

Debian-пакет и AppImage для Linux с соответствующим комплектом официальных плагинов. Расширение браузера и сервер синхронизации в этой сборке не менялись.
