# Verstak v0.1.6

## Highlights

- Existing Deals can now be edited after creation. The **Edit Deal** dialog lets you change the Deal name and its enabled workspace tools.
- Projects can be added to an existing Deal, so Deals created without the Projects tool are no longer stuck without the Project tab.
- Tool changes are applied immediately to an open Deal; newly enabled tabs appear without restarting Verstak.
- Disabling a tool does not delete its existing provider data. Re-enabling the tool makes that data available again.
- Required workspace folders are created when a tool that needs them is enabled.
- Legacy Deals without an explicit `workspaceTools` snapshot keep their previous behavior, and older template metadata can correctly recover the Projects feature.

## Главное

- Уже созданные Дела теперь можно редактировать. Диалог **«Редактировать Дело»** позволяет изменить название Дела и набор подключённых инструментов.
- В существующее Дело можно добавить «Проекты», поэтому Дело, созданное без Projects, больше не остаётся навсегда без вкладки Project.
- Изменения набора инструментов применяются сразу: новая вкладка появляется в открытом Деле без перезапуска Верстака.
- Отключение инструмента не удаляет уже существующие данные его плагина. После повторного включения они снова доступны.
- При включении инструмента Верстак создаёт необходимые ему каталоги, если их ещё нет.
- Для старых Дел без явного `workspaceTools` сохранена совместимость; старые метаданные шаблонов теперь также корректно восстанавливают признак Projects.

## Tests / Тесты

- Added backend regression coverage for changing the exact workspace tool set while preserving disabled-provider data.
- Added Playwright coverage for the real regression scenario: create a Deal without Projects, enable Projects through Edit Deal, and verify that the Project tab appears immediately.

## Packages / Пакеты

Debian package and AppImage for Linux, plus the Windows x64 ZIP, with the matching official plugins bundled. The browser extension and sync server are unchanged in this release.

Debian-пакет и AppImage для Linux, а также ZIP для Windows x64 — с соответствующим комплектом официальных плагинов. Расширение браузера и сервер синхронизации в этом релизе не менялись.
