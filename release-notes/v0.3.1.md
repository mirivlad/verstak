# Verstak v0.3.1 — Секреты в заметках

## Если забыт мастер-пароль

- Действие «Забыли мастер-пароль?» сохраняет всё старое зашифрованное хранилище в архиве, затем позволяет создать новое с другим паролем.
- Для старого архива по-прежнему нужен старый пароль. Архивирование не расшифровывает старые записи и не изменяет их содержимое.
- При ошибке архивирования исходное хранилище остаётся на месте. Пропавший файл проверки рядом со старыми записями больше не приводит к созданию нового ключа поверх них.

## Секрет рядом с заметкой

- Кнопка с ключом в редакторе показывает секреты текущего Дела и общие секреты. Выделенный текст — например, «логин/пароль» — становится подписью ссылки.
- Ссылка открывает окно поверх заметки. Логин и значение доступны для выделения и копирования; «Изменить» открывает поля в этом же окне.
- Мастер-пароль вводится один раз до завершения приложения или переоткрытия/смены хранилища. Для разблокировки можно нажать Enter.
- Изменение сохраняет ID секрета и привязку к Делу. Ошибка сохранения оставляет введённый новый пароль в форме для повторной попытки.
- В Markdown, настройки и журнал приложения значения секретов автоматически не записываются. Заметка хранит ссылку.
- Окно следует светлой или тёмной теме и возвращает фокус на ссылку после закрытия.

## English

- Safely archive an inaccessible encrypted store and create a fresh one without overwriting old records or missing metadata.
- Insert links to current-Deal and shared secrets, using selected text as their labels.
- Open a credential dialog above the current note; copy or edit login/value fields without leaving the note.
- Unlock once per application/vault session, including Enter submission. Preserve record identity, Deal scope and form input on write errors.
- Keep secret values out of Markdown, app settings and application logs; follow both appearance themes.
