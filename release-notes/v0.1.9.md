# Verstak v0.1.9

## UX polish

- Renames the user-facing **Project Meta** workspace tool to **Project / Проект**.
- Renames the global **Project portfolio** entry to **Projects / Проекты**.
- Reworks Project, Milestones and Git workspace surfaces to use the available content width instead of narrow centered forms.
- Project fields, statuses, priorities and dates are properly localized in Russian.
- Project, Milestones and Git selects now use the common dark Verstak control styling.
- Adds Desktop E2E coverage for the Project/Milestones/Git layout and select styling.

## Git checkout names

- Managed Git working copies now use a human-readable repository folder derived from the remote URL, e.g. `Repositories/sshkeeper`.
- Stable `repo-<uuid>` values remain internal repository descriptor IDs and are no longer exposed as normal checkout folder names.
- Existing managed `repo-<uuid>` checkouts are migrated in place when the descriptor resolves to a better checkout name; `.git` and the working tree are preserved.
- Name collisions are resolved with readable suffixes such as `repository-2`.

## Визуальные исправления

- **«Метаданные дела»** заменены на **«Проект»**, а **«Портфель дел»** — на **«Проекты»**.
- Экраны Проекта, Вех и Git переработаны и теперь нормально используют ширину окна.
- Выпадающие списки приведены к общему тёмному стилю Верстака.
- Git больше не показывает пользователю UUID-подобное имя папки рабочего checkout.
