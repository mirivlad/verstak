# Verstak v0.3.4 — Материалы без расширения браузера

- В разделе «Браузер» появилась кнопка «Добавить материал»: ссылка HTTP(S), текст или оба поля, необязательное название и выбор Дела.
- Во вкладке «Браузер» внутри Дела новый материал сразу привязан к этому Делу. Из текста без ссылки тоже можно создать заметку.
- Если сохранение не удалось подтвердить, форма сохраняет введённое. Повторная отправка обновляет ту же запись без дубликата.
- Одновременные поступления из расширения и ручное добавление сохраняются атомарно.
- Форма поддерживает светлую и тёмную темы, управление клавиатурой и возврат фокуса после закрытия.

Очередь Browser Inbox остаётся локальной для устройства. Созданные из неё заметки и файлы синхронизируются обычным способом.

## English

- Add a link, text, or both directly to Browser Inbox, with an optional title and Deal assignment.
- The Deal tab assigns new materials to the current Deal; text-only materials can become notes.
- Keep form input on errors and retry without creating duplicate records.
- Preserve concurrent extension captures with atomic record updates.
- Support both themes, keyboard navigation and focus restoration.

The Inbox queue stays device-local; converted notes and files use normal sync.

**Official plugins / Официальные плагины:** v0.2.8.
