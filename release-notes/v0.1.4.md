## Highlights

- Projects is now a first-class tool in a Project Deal. A project keeps its own name, description, status, priority, tags, milestones, links, workspace link, and lightweight history. Project Deals open with the Project tab alongside Notes, Files, Todos, Journal, Activity, and Browser.
- Projects coordinates the tools already in Verstak instead of owning copies of them. Tasks, Notes, Files, and Activity appear through their plugin capabilities; if one of those plugins is disabled, the Project remains usable and that integration simply disappears.
- Plugin-to-plugin operations no longer require a consumer to know which concrete plugin implements a capability or which command ID it uses. The desktop resolves an active provider only after checking that the consumer declared the capability, then executes the provider's published operation.
- Notes and Todos now publish project-facing operations used by Projects through that provider-independent bridge.

## Главное

- Проекты теперь — полноценный инструмент в проектном Деле. У проекта есть свои название, описание, статус, приоритет, теги, этапы, ссылки, привязка к Делу и лёгкая история изменений. В шаблоне `Project` вкладка `Project` появляется рядом с Notes, Files, Todos, Journal, Activity и Browser.
- Projects не копирует уже существующие инструменты, а связывает их. Задачи, заметки, файлы и активность подключаются через возможности соответствующих плагинов; если какой-то плагин отключён, сам проект продолжает работать, а недоступная интеграция просто исчезает.
- Межплагиновые операции больше не требуют знать конкретный plugin ID или command ID провайдера. Ядро сначала проверяет, что потребитель объявил capability, затем находит активного провайдера и вызывает опубликованную им операцию.
- Notes и Todos публикуют проектные операции, которыми Projects пользуется через этот независимый от провайдера мост.

## Under the hood / Под капотом

- Provider manifests can map stable capability operations to their internal commands through `capabilityOperations`; consumers call them with `api.capabilities.invoke(...)`.
- The E2E official-plugin catalog now runs the real Projects manifest, frontend, and localization instead of pretending the fifteenth plugin does not exist.
- This release pins official plugins to `f49878284e6a1fe15cf95f4040d1c4f6a50ab058`, so the packages are reproducible even if plugin `main` moves later.

## Packages / Пакеты

Debian package and AppImage for Linux, plus the Windows x64 ZIP, all with the matching official plugins bundled. The browser extension and sync server are unchanged in this release.

Debian-пакет и AppImage для Linux, а также ZIP для Windows x64 — со строго соответствующим комплектом официальных плагинов. Расширение браузера и сервер синхронизации в этом релизе не менялись.
