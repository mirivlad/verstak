# Verstak v0.2.8

## Плагины

- Плагин, написанный под другую версию API плагинов, теперь не запускается, а получает в Менеджере плагинов понятный статус «несовместим» с указанием обеих версий. Раньше такой плагин загружался и ломался позже на вызове, которого уже нет. Плагины, зависящие от него, показывают «нет зависимости».
- Статусы «несовместим» и «нет зависимости» переведены; прежде в русском интерфейсе они показывались служебными английскими словами.

## Для разработчиков плагинов

- SDK описывает все разделы API, которые приложение даёт плагинам: добавлены `keys`, `notifications`, `secrets` и `files.openURL`. Проверка в CI не даст приложению и SDK снова разойтись.
- Внутреннее: крупнейший файл приложения разделён по областям. Поведение не меняется.

## Plugins

- A plugin written for another plugin API version no longer starts; the Plugin Manager marks it incompatible and names both versions. It used to load and then fail on a call that no longer existed. Plugins that depend on it report a missing dependency.
- The incompatible and missing-dependency states are now translated instead of showing internal identifiers.

## For plugin authors

- The SDK now declares every API namespace the application hands to plugins, including `keys`, `notifications`, `secrets` and `files.openURL`. A CI check keeps the application and the SDK from drifting apart again.
- Internal: the application's largest source file is split by concern. Behaviour is unchanged.

**Official plugins / Официальные плагины:** v0.2.0.
