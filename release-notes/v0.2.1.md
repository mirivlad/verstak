# Verstak v0.2.1

## Fixed

- Editing a Deal created before v0.2.0 no longer fails when its saved tool list
  still contains a retired service plugin such as Activity. Verstak removes
  those obsolete navigation entries while preserving all provider-owned data
  and the current Deal tools you selected.
- New Deals and templates still reject service plugins as Deal tools, so a
  mistaken or unsupported recipe is not silently accepted.

**Full Changelog**: https://github.com/mirivlad/verstak/compare/v0.2.0...v0.2.1
