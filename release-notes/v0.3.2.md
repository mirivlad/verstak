# Verstak v0.3.2 — Быстрее вернуться к работе

- В Обзоре Дела появляются до трёх последних изменённых заметок с названием, путём и временем изменения.
- Нажатие на карточку открывает именно эту заметку. Карточка ключевого ресурса открывает указанный файл; общий счётчик заметок по-прежнему открывает список.
- Если файл успели переместить или удалить, приложение оставляет список заметок и объясняет, почему открыть файл не удалось.
- Действия карточек с конкретной целью подписаны «Открыть». У кнопки ресурса есть доступное имя с названием файла.

## English

- Resume recently modified notes directly from the Deal Overview, with their actual titles and timestamps.
- Open the exact note or key resource while keeping the Notes total linked to the list.
- Keep the list available with a useful error when a file no longer exists.
- Use clear, contextual action labels for resource cards.
