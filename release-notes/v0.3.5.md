# Verstak v0.3.5 — Действия 2.0

- Вернулись пользовательские «Действия»: запуск приложений и скриптов, консольные команды с результатом и открытие HTTP(S)-ссылок. Есть общий раздел и вкладка каждого Дела.
- Компактная карточка с названием и иконкой запускается нажатием. Управление появляется при наведении или фокусе; иконки выбираются в общем окне поиска, аргументы вводятся обычной строкой с кавычками.
- Созданные и изменённые через форму действия запускаются сразу. Новые импортированные или синхронизированные команды требуют одного подтверждения на устройстве; внешнее изменение программы, аргументов или рабочего каталога снова требует подтверждения.
- Для опасных команд можно включить «Спрашивать подтверждение перед каждым запуском». Доверие остаётся на устройстве и не переносится через синхронизацию или импорт.
- Консольный вывод ограничен по размеру и времени; длительную команду можно остановить. Программы получают отдельный массив аргументов без неявного shell. Плагин по-прежнему должен иметь разрешение на запуск процессов.

Синхронизация, импорт, запуск приложения и открытие Дела не выполняют команды автоматически. Существующие определения Actions 2.0 сохраняются; определения без локальной записи доверия потребуют одного подтверждения. Пути к программам на разных устройствах могут отличаться.

## English

- Actions return as a plugin: launch applications and scripts, run console commands with output, and open HTTP(S) links globally or within a Deal.
- Launch from compact cards; edit and reorder on hover or focus. Use the shared searchable icon picker and a plain argument line with quote grouping.
- Actions saved through the form are trusted locally. Imported or synced commands require one confirmation on each device; external changes to executable parameters require confirmation again.
- Optionally ask before every run. Local trust never travels through sync or import, and no action runs automatically.
- Keep process permissions, literal argument arrays, execution and output limits, and cancellation. Existing Actions 2.0 definitions remain compatible.

**Official plugins / Официальные плагины:** v0.2.9.
