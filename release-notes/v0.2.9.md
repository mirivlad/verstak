# Verstak v0.2.9

## Исправлено

- Windows: плагины снова показывают свои подписи на выбранном языке. Если путь к плагинам проходил через ссылку или короткое имя Windows (например, `RUNNER~1`), каталоги переводов отвергались, и вместо текста были видны служебные ключи. То же случалось на Linux, если каталог установки был символической ссылкой.
- Windows и macOS: переименование, которое меняет только регистр букв (`client` → `Client`, `заметка.md` → `Заметка.md`), больше не отклоняется как «уже существует».

## Новое

- Настройки → Основное → Обновления: можно проверить, есть ли новая версия Верстака. Проверка при запуске выключена по умолчанию — приложение не обращается в сеть без вашего согласия. Ничего не скачивается: найденная версия открывается ссылкой на страницу выпуска, а в строке состояния появляется значок.

## Fixed

- Windows: plugins show their own text again. A plugin directory reached through a link or a Windows short name (such as `RUNNER~1`) made every translation catalog look like it escaped the plugin, so raw keys were shown. The same happened on Linux when the install directory was a symlink.
- Windows and macOS: a rename that only changes letter case (`client` → `Client`) is no longer refused as already existing.

## New

- Settings → General → Updates: check whether a newer Verstak exists. The startup check is off by default, so the application does not reach the network unless you allow it. Nothing is downloaded; a newer release links to its page and shows a badge in the status bar.

**Official plugins / Официальные плагины:** v0.2.0.
