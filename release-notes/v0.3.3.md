# Verstak v0.3.3 — Сохранение последних правок

- Исправлена потеря последней несохранённой правки при быстром закрытии заметки или текстового файла, до срабатывания таймера черновика.
- Редактор завершает запись черновика перед освобождением своего API. Если предыдущая запись ещё идёт, последнее изменение сохраняется после неё.
- При быстром переоткрытии приложение дожидается записи и восстанавливает последнюю версию черновика. Сам файл при этом не сохраняется автоматически: действие «Сохранить» продолжает работать отдельно.
- Восстановленный черновик открывается в режиме редактирования, даже если заметку открыли для чтения. Это также относится к действию «Восстановить черновик» при внешнем изменении файла.

## English

- Preserve the latest unsaved edit when leaving a note or text file before the draft timer runs.
- Finish queued draft writes before releasing the editor API, and wait for cleanup before reopening the plugin.
- Restore the latest draft without implicitly saving the underlying file.
- Open recovered drafts for editing, including recovery after an external file change, instead of letting preview mode save them automatically.
