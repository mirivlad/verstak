# Verstak v0.1.8

## Hotfix

- Restores **Edit Deal**, which was accidentally removed during the Deal-only refactor in v0.1.7.
- Existing Deals can again change their name and enabled workspace tools from the Deal context menu.
- Editing now uses the canonical Deal UUID metadata path; the retired legacy workspace manager is not restored.
- Disabling a Deal tool does **not** delete that plugin's existing Deal-owned data. Re-enabling the tool restores access to the same data.
- The Edit Deal tool list is built from currently discovered workspace-capable plugins and reflects the exact `workspaceTools` set stored in canonical Deal metadata.
- Fixes the E2E Wails mock so renaming a Deal preserves its UUID, matching the real Deal-only runtime.

## Исправление

- Возвращено **«Редактировать Дело»**, случайно удалённое во время Deal-only рефакторинга в v0.1.7.
- У существующего Дела снова можно изменить имя и набор подключённых инструментов через контекстное меню.
- Редактирование работает через канонические UUID-метаданные Дела; старый `workspace.Manager` не возвращался.
- Отключение инструмента у Дела **не удаляет** уже существующие данные этого плагина. После повторного включения данные снова доступны.
- Список инструментов строится из обнаруженных workspace-плагинов и сохраняет точный `workspaceTools` канонического Дела.
- Исправлен E2E Wails mock: переименование Дела теперь сохраняет UUID, как и реальный Deal-only runtime.

## Regression coverage

A new Playwright regression test creates a Deal, edits its tools, removes Project Meta, verifies that its plugin-owned data survives, then enables Project Meta again and verifies that the same data is still present.

Новый Playwright regression-тест создаёт Дело, меняет его инструменты, отключает Project Meta, проверяет сохранность plugin-owned данных, затем включает Project Meta обратно и убеждается, что данные остались на месте.
