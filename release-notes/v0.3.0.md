# Verstak v0.3.0 — Студия

## Интерфейс

- Нейтральные светлая и тёмная темы с акцентом индиго. Основные кнопки используют белый текст.
- Переключатель темы в шапке; в «Настройки → Основное» доступны светлая, тёмная и системная темы. Выбор сохраняется между запусками.
- Обновлены боковая панель, шапка, вкладки Дела и Обзор. Создание Дела стало заметным действием, настройки находятся внизу навигации, состав инструментов доступен рядом с вкладками.
- Боковая панель сворачивается; в узком окне открывается поверх рабочей области. Диалоги и клавиатурный фокус учитывают это поведение.
- Официальные плагины и Markdown-редактор используют общую тему, включая формы, предпросмотр и подсветку кода.

## Создание Дела

- Исправлена передача расположения при клике на создание: значение события мыши больше не становится ID папки.
- Ошибки backend корректно доходят до формы. Конфликт имени сохраняет введённые данные; успешное создание открывает Дело и раскрывает родительскую папку.
- Старые рецепты очищаются от выведенного из употребления инструмента Activity с сохранением пользовательских полей и прочих инструментов.

## English

- Introduce the Studio shell with neutral light/dark palettes, indigo actions and readable white button labels.
- Save appearance preferences, follow the system appearance, or switch directly from the header.
- Refresh navigation, Deal tabs and Overview; expose Deal tools next to the tabs and keep narrow windows usable with a navigation drawer.
- Make official plugin surfaces and the Markdown editor follow the host theme.
- Fix Deal creation from real mouse clicks, propagate backend errors, preserve form input on conflicts, open created Deals and migrate retired Activity entries in stored templates.

**Official plugins / Официальные плагины:** v0.2.3.
