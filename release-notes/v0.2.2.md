# Verstak v0.2.2

## Fixed

- When a Deal is open, the “Search in this Deal” checkbox now stays on the
  same row to the right of the global search field.
- XFCE can now associate the Verstak window with its desktop entry and show
  the branded application icon in the panel. The desktop entry and the GTK
  window use the same `verstak-desktop` window class.

**Full Changelog**: https://github.com/mirivlad/verstak/compare/v0.2.1...v0.2.2
