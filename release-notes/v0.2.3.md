# Verstak v0.2.3

## Fixed

- The synchronization indicator in the status bar now updates after the connection or sync state changes, instead of remaining at “Not configured”.
- Settings use the available width of the application window.
- Deal template and milestone actions have additional guards against accidental changes or deletion.

## Improved

- Deal templates are managed from Settings; service plugins no longer occupy workspace navigation.
- Journal review and Git actions have clearer labels and feedback.

## Исправлено

- Индикатор синхронизации в строке состояния обновляется при изменении подключения или состояния синхронизации и больше не застревает на «Не настроено».
- Настройки занимают доступную ширину окна приложения.
- Действия с шаблонами дел и вехами лучше защищены от случайных изменений и удаления.

## Улучшено

- Шаблоны дел управляются из настроек; служебные плагины не занимают место в навигации по рабочей области.
- Действия с журналом и Git получили более понятные подписи и обратную связь.
