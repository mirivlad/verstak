# Verstak v0.2.10

## Редактор заметок

- Панели редактора стали компактными: иконки с подсказками вместо надписей, без лишнего переноса кнопок на узких экранах.
- Теперь можно прикреплять изображения и файлы кнопкой, перетаскиванием или вставкой из буфера обмена. Вложения хранятся рядом с заметкой и отображаются в режиме чтения.
- Существующие ссылки можно изменять по Ctrl+K.
- Добавлены горячие клавиши: Ctrl+S — сохранить, F2 — переименовать заметку, Ctrl+E — чтение/редактирование, Ctrl+Shift+E — режим рядом, а также сочетания для форматирования текста и списков.
- Переименование сохраняет старые названия как псевдонимы, чтобы ссылки на заметку продолжали работать.
- Парные скобки и кавычки, контекстная панель форматирования выделения, справка по горячим клавишам.

## Notes editor

- Compact icon toolbars with accessible tooltips and responsive scrolling.
- Add local image/file attachments by picker, drag-and-drop or clipboard; images appear in preview.
- Edit existing links with Ctrl+K; keyboard shortcuts for saving, renaming, view modes and Markdown formatting.
- Rename preserves old titles as aliases, keeping existing wiki links functional.
- Automatic bracket/quote pairing, selection formatting toolbar and shortcut reference.
