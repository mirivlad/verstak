# Verstak v0.2.7

## Обслуживание

- Интерфейс приложения переведён на Svelte 5 и Vite 8. Внешне ничего не должно измениться; обновление закрывает известные уязвимости в инструментах сборки интерфейса.
- В комплекте официальные плагины v0.2.0 — их настройки синхронизации и импорта обновлены так же.

## Maintenance

- The application interface moves to Svelte 5 and Vite 8. Nothing should look different; the upgrade closes known vulnerabilities in the interface build tooling.
- Bundles official plugins v0.2.0, whose sync and import screens received the same upgrade.

**Official plugins / Официальные плагины:** v0.2.0.
