# Verstak v0.1.7

## Highlights

- **Deal is now the single workspace scope.** The old nested `Deal → Project` runtime model has been removed; Deal UUID is the canonical identity for Notes, Files, Todo, Activity, Journal, Milestones and other workspace capabilities.
- **Project Meta replaces nested Projects.** A Deal can optionally gain project metadata, and the global Portfolio shows only Deals that actually have Project Meta enabled.
- **Templates are now plugin-owned recipes.** General, Project, Writing, Admin and Minimal templates are persisted and editable, can be duplicated, and create ordinary Deals from a snapshot of enabled tools and initial content.
- **Milestones are independent.** They are a normal Deal plugin and no longer depend on a nested Project container.
- **Git integration is now functional.** A Deal can manage multiple repositories: clone or adopt an existing checkout, show branch and working-tree status, changed/untracked files, ahead/behind state and recent commits, and run fetch, fast-forward pull and push.
- **Git credentials stay backend-side.** Secret references are resolved only for the Git operation; HTTPS credentials use a temporary askpass helper and SSH keys use temporary protected files. Raw credentials are not persisted in repository descriptors or Git errors.
- **Git checkouts are device-local.** Managed `<Deal>/Repositories/**` working trees are excluded from ordinary Verstak Sync while repository descriptors remain syncable. A second device can therefore see a repository as “not cloned on this device” and clone it locally.
- **Existing data is migrated on first start.** The one-shot Deal-only migration preserves ordinary Notes, Files and provider data, migrates Project Meta, Milestones and Journal worklogs, and leaves the new runtime on canonical UUID-keyed Deal metadata.

## Главное

- **Дело теперь является единственным рабочим контейнером.** Старая runtime-модель `Дело → Проект` удалена; каноническая идентичность — UUID Дела, которым пользуются Заметки, Файлы, Задачи, Активность, Журнал, Этапы и остальные инструменты.
- **Вложенные Проекты заменены на Project Meta.** Любое Дело при необходимости может получить свойства проекта, а глобальный Портфель показывает только те Дела, где Project Meta действительно включён.
- **Шаблоны стали самостоятельным плагином.** General, Project, Writing, Admin и Minimal хранятся как редактируемые рецепты, поддерживают дублирование и создают обычное Дело с выбранным набором инструментов и начальным содержимым.
- **Этапы (Milestones) больше не зависят от Проектов.** Это обычный независимый инструмент Дела.
- **Git теперь не заготовка, а рабочая интеграция.** В одном Деле можно держать несколько репозиториев, клонировать их или подхватывать существующие, видеть ветку, dirty/clean, изменённые и untracked-файлы, ahead/behind и последние коммиты, а также делать fetch, fast-forward pull и push.
- **Секреты Git не уходят во frontend.** Ссылка на секрет разрешается на backend только на время операции; для HTTPS используется временный askpass, для SSH — временный файл ключа с ограниченными правами. Пароли, токены и ключи не записываются в descriptor или ошибки Git.
- **Рабочие копии Git локальны для устройства.** Управляемые каталоги `<Дело>/Repositories/**` целиком исключаются из обычной синхронизации Верстака, а descriptor репозитория синхронизируется. На другом компьютере такой репозиторий отображается как ещё не клонированный и может быть получен локально.
- **При первом запуске выполняется одноразовая миграция.** Полезное содержимое — Заметки, Файлы и provider data — сохраняется; Project Meta, Milestones и записи Журнала переводятся в новую Deal-only модель с UUID-keyed metadata.

## Upgrade note / Обновление

This release contains a structural migration from the v0.1.6 workspace/project model. Verstak performs it once before the new runtime starts. As with any migration of a real vault, keep a current backup before opening important data with v0.1.7 for the first time.

В этом релизе есть структурная миграция модели Дел и Проектов из v0.1.6. Верстак выполняет её один раз до запуска нового runtime. Перед первым открытием важного рабочего хранилища в v0.1.7 рекомендуется иметь актуальную резервную копию.

## Tests / Тесты

- Desktop CI and the complete Playwright suite are green: **174/174 E2E tests passed** before the release cut.
- Added coverage for optional Project Meta portfolio filtering, template duplication, managed Git checkout sync exclusion, secure transient Git credentials, the public Git plugin bridge, clone/status/network operations, and adopting an existing local checkout.
- The Deal-only migration and canonical UUID metadata paths have backend regression coverage, including provider data, milestones and Journal worklogs.

## Packages / Пакеты

Debian package and AppImage for Linux, plus the Windows x64 ZIP, with the matching official plugins bundled. The browser extension and sync server are unchanged in this release.

Debian-пакет и AppImage для Linux, а также ZIP для Windows x64 — с соответствующим комплектом официальных плагинов. Расширение браузера и сервер синхронизации в этом релизе не менялись.
