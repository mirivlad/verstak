# Verstak v0.2.0

## Deal navigation

- Deal tool tabs are paged instead of horizontally scrolled: use the edge arrow
  to reveal the next or previous group of tools.
- Global Search can now be limited to the currently open Deal with one
  checkbox beside the search field.
- Project and Milestones stay independent plugins. When both are enabled for a
  Deal, Milestones appears as a section inside Project; with only Milestones
  enabled it remains a standalone Deal tool.
- Activity, Milestones, Templates, and the old Deal Search surface no longer
  add redundant sidebar or Deal navigation entries. Activity continues to run
  as a background provider for Journal.

## Templates and journal

- Templates are managed in **Settings → Templates**. The New Deal dialog now
  presents saved recipes directly.
- Template tools are selected by readable installed-plugin cards rather than
  raw plugin IDs. Duplicate creates an independent copy.
- Journal proposal review is wider and groups repeated activity actions into
  collapsed, selectable evidence groups.

## Git and Linux desktop integration

- Git cards show an in-progress operation, disable conflicting actions, and
  retain a success or failure result after fetch, pull, push, and related
  operations.
- Project, Milestones, and Git no longer repeat their selected tab name as a
  large workspace heading.
- Debian and AppImage packages now install raster hicolor icon sizes and align
  the GTK window class with the desktop entry for XFCE panel matching.
