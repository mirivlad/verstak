# Verstak v0.2.5

## Новый редактор заметок

- Рабочие Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z, включая русскую раскладку, форматирование и переключение режимов.
- Для ссылки на другую заметку нажмите «Ссылка на заметку», Ctrl+K или начните вводить `[[`. Выберите нужную заметку; старые ссылки после переименования продолжают работать.
- Чекбоксы задач в просмотре стали крупнее, доступны с клавиатуры и автоматически сохраняют изменения в Markdown.
- Режимы «Редактировать», «Чтение» и «Рядом». В чтении нет неработающих кнопок форматирования.
- Оглавление, обратные ссылки с контекстом, подсветка и копирование кода, таблицы и вложенные списки.
- История форматирования и замены текста, восстановление черновиков и предупреждение при изменении файла извне.

## Notes editor

Persistent editing history, reliable shortcuts, discoverable note linking, interactive tasks, improved reading and code highlighting. Existing Markdown files and note aliases remain compatible.
