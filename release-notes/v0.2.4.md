# Verstak v0.2.4

## Notes

- Note links and backlinks are available in the Markdown editor.
- Renaming a note keeps older `[[title]]` links working: the link text remains unchanged and opens the renamed note.
- Alias metadata is hidden while editing and preserved on save. Ambiguous links do not choose an arbitrary note.

## Заметки

- В Markdown-редакторе доступны исходящие и обратные ссылки заметок.
- После переименования заметки прежние ссылки `[[название]]` продолжают работать: их текст остаётся прежним, а открывается переименованная заметка.
- Служебные данные псевдонимов скрыты при редактировании и сохраняются при записи. Неоднозначная ссылка не открывает произвольную заметку.

**Official plugins / Официальные плагины:** v0.1.4.
