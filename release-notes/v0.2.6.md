# Verstak v0.2.6

## Release process

- The application itself is unchanged from v0.2.5. This release exists to prove that a pushed version tag now builds and publishes on its own.
- The official plugins bundled into the installers are pinned in the repository, not guessed from the application's version number. The pin and these notes are checked against each other before a build starts.
- Release script checks that had silently stopped running are part of the regular test suite again.

## Процесс выпуска

- Само приложение не изменилось по сравнению с v0.2.5. Этот выпуск нужен, чтобы убедиться: пуш тега версии теперь сам собирает и публикует релиз.
- Версия официальных плагинов, которые входят в установщики, закреплена в репозитории, а не угадывается по номеру версии приложения. Перед сборкой она сверяется с этими заметками.
- Проверки релизных скриптов, которые незаметно перестали запускаться, снова входят в обычный набор тестов.

**Official plugins / Официальные плагины:** v0.1.5.
